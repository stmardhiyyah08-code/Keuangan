# Dompetku - Aplikasi Keuangan

Aplikasi Manajemen Keuangan Pribadi & Usaha dengan integrasi Penasihat Keuangan AI Gemini.

## Fitur Utama
- **Manajemen Transaksi**: Catat pemasukan dan pengeluaran.
- **Dompet & Rekening**: Kelola berbagai dompet/rekening bank.
- **Kategori & Anggaran**: Atur batas anggaran bulanan per kategori.
- **Analisis AI**: Rekomendasi keuangan pintar dan pemindai struk belanja berbasis Gemini AI.
- **Target Keuangan**: Lacak progres tabungan dan impian Anda.

## Cara Menjalankan

1. Install dependensi:
   ```bash
   npm install
   ```

2. Jalankan server pengembang:
   ```bash
   npm run dev
   ```

3. Buka di browser:
   `http://localhost:3000`
